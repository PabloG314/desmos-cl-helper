Tutorial: your first activity with CL Helper

In this tutorial you'll build a small four-screen practice activity in Desmos Activity Builder, describe it to CL Helper, and paste the code it writes back into Desmos. By the end you'll have answer feedback, a hint that appears after the first try, a self-checking table, and a graph that plots a student's own equation. Plan on about 20 minutes.

You don't need to know any Computation Layer (CL) to follow along. CL Helper writes all of the code. Your job is to build the screens in Desmos, give each component a name, and paste code where the helper tells you to. CL Helper never connects to Desmos or changes anything there. It only gives you text to copy.

Part 1: Build the skeleton in Desmos

Want to skip this part? Open the ready-made skeleton activity and make your own copy so you can edit it. All four screens and component names are already set up, so you can go straight to Part 2.

Create a new, blank activity in Desmos Activity Builder and add four screens. Give each component the exact name shown, using its name field in the editor. Names are case-sensitive.

Screen 1

  1. Add a math input with the prompt What is 3 × 4? Name it s1_math1.
  2. Add a note. Leave it empty and name it s1_note1.
  3. Add a second note with the text Hint: 3 × 4 means three groups of four. Name it s1_note2.

Screen 2

  1. Add a table with 2 columns and 3 rows, not counting the header row. Name it s2_table1.
  2. Label the column headers x and y.
  3. Type 1, 2, and 3 down the x column. Leave the y cells blank.
  4. Add the prompt Fill in the table for y = 2x + 1.

Screen 3

  1. Add a math input with the prompt Write the equation of a line. Name it s3_math1.
  2. Add a second math input with the prompt Choose a slope. Name it s3_math2.

Screen 4

  1. Add a graph and name it s4_graph1.
  2. In the graph, add the expressions y = f(x) and y = a x.
  3. If Desmos offers to add a slider for a, don't add it. Leave f undefined, even if Desmos shows a warning on it.

Part 2: Map the activity in CL Helper

Now tell CL Helper what's in the activity. This is called the map.

  1. Open CL Helper and click New activity. Give it a title, such as CL Helper Tutorial.
  2. Set Screens to 4.
  3. On each screen card, use the + buttons to add components:
    • Screen 1: one Math input and two Notes
    • Screen 2: one Table
    • Screen 3: two Math inputs
    • Screen 4: one Graph
  4. When you add the table, CL Helper asks three questions. Answer 3 rows, 2 columns, and 2 for the column students fill in.
  5. Check that the names next to each counter match the names you used in Desmos, then click Map view →.

The order you press the buttons in doesn't matter. Names are numbered by type on each screen, so the first note on Screen 1 is always s1_note1.

Part 3: Add behaviors

The map view shows each screen as a card. Click a component's name to open its panel on the side. The panel lists what that component can do. After you save a behavior, the panel goes back to that list, where you'll see the new behavior with Edit and Remove buttons and a Generated code section showing the code it produced. Components that have a behavior are marked with ⟷ on the map.

You may also see an Ideas panel suggesting links such as plotting a math input on a later graph. Those are suggestions only. For this tutorial, follow the steps below.

1. Feedback on the Screen 1 answer

  1. Click s1_math1 and choose Add input feedback.
  2. Set Target note to s1_note1. This is where the feedback will appear.
  3. Set Correct answer to 12. Leave Tolerance at 0.001.
  4. For Correct message, type Nice, 3 × 4 = 12. For Fallback message, type Not quite. Try again.
  5. Leave Set dashboard correct checked. This gives the student a green check on your teacher dashboard when they get it right.
  6. Under Rules, pick Sign error and click + Add rule. Give it the message Check your sign. Can two positive numbers multiply to a negative?
  7. Add a Place value rule the same way, with the message Close! Check your place value. This rule catches answers like 1.2 and 120.
  8. Click Save.

Rules are checked in order, after the correct answer and before the fallback. The first one that matches decides the message.

2. A hint that appears after the first try

  1. Click s1_note2 and choose Show/hide on submit.
  2. Set Reveal when this input is submitted to s1_math1, then click Save.

The hint stays hidden until the student presses submit the first time. After that it stays visible, even if they change their answer.

3. Check the table cell by cell

  1. Click s2_table1 and choose Add table feedback.
  2. Leave the suffixes as ✅ and ❌.
  3. Under Correct values per cell, enter 3 for row 1, 5 for row 2, and 7 for row 3. These are the y values for x = 1, 2, and 3.
  4. Click Save.

The check mark or X appears next to each answer once the student clicks out of the cell, so they aren't graded halfway through typing.

4. Plot the student's equation

  1. Click s3_math1 and choose Carry value to a graph.
  2. Set Destination to s4_graph1.
  3. Set Carry type to Expression → graph function.
  4. Type f for the function name and click Save.

5. Use the student's slope

  1. Click s3_math2 and choose Carry value to a graph.
  2. Set Destination to s4_graph1.
  3. Set Carry type to Number → graph variable.
  4. Type a for the variable name and click Save.

The names f and a match the expressions you typed into the graph in Part 1. That's how the graph knows where the student's answers go.

Part 4: Copy the code into Desmos

Click Generate code → at the top of the map view. The code page lists one script for each component that needs code, grouped by screen. You should see five: s1_math1, s1_note1, s1_note2, s2_table1, and s4_graph1. The Screen 3 inputs don't need code of their own. The graph reads from them.

For each script:

  1. Read the location line, for example Screen 1 → s1_math1 → CL. That's the component the code belongs to.
  2. Read any setup reminders listed above the code.
  3. Click Copy.
  4. In Desmos, open that component's Computation Layer editor, paste the code, and close the editor.

Each script has a status badge. New means you haven't copied it yet. Up to date means you copied the current version. Needs re-copying means you changed something in CL Helper after copying, so the version in Desmos is out of date.

What the code looks like

You never have to edit the code, but it helps to recognize it. The graph's script, for example, looks like this: 

# >>> cl-helper carry 3f2a9c
function("f"): simpleFunction(s3_math1.latex, "x")
# <<< cl-helper carry 3f2a9c

# >>> cl-helper carry 8b41d0
number("a"): s3_math2.numericValue
# <<< cl-helper carry 8b41d0

The lines starting with # are comments that mark which part of the script came from which behavior. The letters and numbers after them will be different in your copy. The hint's script is a single line, hidden: s1_math1.submitCount < 1, which reads as "stay hidden until s1_math1 has been submitted at least once."

Part 5: Test it as a student

Open the activity in student preview and try each of these. Each line says what you should see.

  • Screen 1: before you submit, both notes are hidden.
  • Screen 1: submit -12. The sign error message appears and the hint shows up.
  • Screen 1: submit 120. You get the place value message.
  • Screen 1: submit 7. You get the fallback message.
  • Screen 1: submit 12. You get the correct message. The hint is still showing.
  • Screen 2: type 3 in the first y cell and click away. A ✅ appears. Type a wrong value in another cell and you get a ❌.
  • Screen 3: enter y = 3x - 2 and a slope of -1.
  • Screen 4: the graph shows your line from Screen 3 and the line y = -x.

If all of that works, you've used every main feature of CL Helper. To add CL to a real activity, build or open it in Desmos, map it in CL Helper the same way, and attach the behaviors you need.

Making changes later

  • Changing a behavior: click the component on the map and choose Edit. The script's badge changes to Needs re-copying. Copy it and paste it over the old code in Desmos.
  • Renaming a component: double-click its name on the map. CL Helper adds a To do in Desmos reminder, because you also have to change the name in Desmos and re-copy any scripts that mention it.
  • Moving components or screens: drag them on the map. If an automatic name has to change (for example a math input moving from Screen 2 to Screen 5), CL Helper will tell you before anything changes.
  • Saving: your work saves in this browser on its own. To move it to another computer, use Export file or Copy share link on the code page.

If something doesn't work

The CL editor shows an error mentioning a name.
The component name in Desmos doesn't match CL Helper. Check spelling and capitalization in both places.
The feedback note never appears.
The feedback waits for the student to press submit. Make sure you pressed it for s1_math1 in student preview.
The graph doesn't show the student's line.
Check that the graph has the expression y = f(x), that f isn't defined anywhere else in the graph, and that the code went into the graph's CL rather than a math input's.
The second line ignores the slope.
If Desmos added a slider for a, delete it. The slider overrides the value from CL.
A table cell never gets a ✅ or ❌.
Click out of the cell. Feedback waits until the cell loses focus.
